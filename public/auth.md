# auth.md

Enable agents to register users without the sign-up form. Auth.md provides secure agent registration that any app can implement.

## Agent Registration Instructions

1. Place this file at your domain root: `https://yourdomain.com/auth.md`
2. Follow the WorkOS Auth.md guide: [workos.com/auth-md](https://workos.com/auth-md)
3. Publish OAuth metadata at:
   - `/.well-known/oauth-protected-resource`
   - `/.well-known/oauth-authorization-server`

[Learn more](/auth-md/docs)
